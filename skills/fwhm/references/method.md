# FWHM 方法与输出

## 1. 共同定义

一维 profile 使用带背景偏置的高斯模型：

$$
I(x)=B+A\exp\left[-\frac{(x-x_0)^2}{2\sigma^2}\right]
$$

观测半高宽为：

$$
\mathrm{FWHM}=2\sqrt{2\ln 2}\,\sigma
$$

拟合使用原始强度和自由 offset。结果是标样或结构与系统 PSF 卷积后的观测宽度，不执行珠径或线径反卷积。

共同质量检查包括：

- 局部稳健 SNR 不低于5。
- 高斯拟合 $R^2$ 不低于0.90。
- 拟合峰中心相对 profile 预定中心偏移不超过1个采样点。
- TIFF profile 在两侧均有足够背景，不允许用截断峰。
- 自动质量合格 ROI 默认纳入；人工审核仅删除明确不合格 ROI。

横向和轴向分别使用 Tukey 上侧外围栏：

$$
F_\mathrm{upper}=Q_3+3\,\mathrm{IQR},\qquad
\mathrm{IQR}=Q_3-Q_1
$$

仅当该方向至少有10个质量合格 ROI 时执行一次，不迭代重算。被排除值保存在诊断结果中。少于10个 ROI 标记为“样本量不足”，10–29个给出警告，至少30个为正常。

## 2. 荧光珠模式

处理流程：

1. Difference-of-Gaussians 抑制缓慢变化背景。
2. 在2D或3D图像中寻找局部极大值候选。
3. 排除 XY 四周各10%的视野边缘区域。
4. 使用中心层二维惯性矩主轴比、质心偏移和近邻距离排除粘连珠、双珠及非单珠结构。
5. 在中心层提取 X/Y profile；在有效 Z 层提取 Z profile。
6. 独立拟合 X、Y、Z 高斯，横向结果取同一珠子的 X/Y FWHM 算术平均。
7. 检查饱和、SNR、$R^2$、中心偏移、Z峰截断和可选预注册物理范围。

严格单珠预设：

- XY 视野边缘排除10%。
- 形状 ROI 半径8 px。
- 横向惯性矩主轴比不超过1.25。
- 横向质心偏移不超过0.75 px。
- 当 Z 层差不超过2时，最近候选横向距离至少13 px。
- DoG detection SNR 100。该数值是检测响应相对背景尺度，不是光子 SNR。
- 单图最多分析500个候选。超过后标记 `too_many_candidates` / “候选太多”，不作为正式结果。

`mp-sim-beads-v1` 使用 XY 30.1 nm、Z 96.9 nm，并排除末两层。通用预设默认排除首尾各一层。

## 3. 线条模式

理论横向和轴向分辨率只用于定义观察与干扰尺度，不进入高斯宽度公式或 Tukey 围栏。

处理流程：

1. 使用 `scikit-image` Sato 亮脊线增强、二值化、骨架化和连通域分析。
2. 每个连通线条最多选择3个 ROI；沿线间距至少为2倍理论横向分辨率。
3. 局部连续线段长度至少为2倍理论横向分辨率，局部方向变化不超过15°。
4. 自动估计切向，并沿严格垂直方向提取横向 profile。
5. profile 中心周围1.5倍理论横向分辨率内出现分支、交叉或第二条线时排除。
6. 线条与 XY 平面夹角超过10°时只排除轴向结果，横向仍可独立保留。
7. 轴向中心上下1.5倍理论轴向分辨率内出现第二个显著峰时，标记轴向干扰。
8. 横向 profile 默认取中心两侧各2倍理论横向分辨率。
9. 轴向 profile 优先取中心两侧各2倍理论轴向分辨率；薄堆栈可降为1.5倍；不足1.5倍时轴向拒绝。
10. 同时计算高斯 FWHM 和背景扣除后的半峰插值 FWHM；差异超过20%时判为非高斯或受干扰 profile。

对于 `ZYX` 数据，先从候选位置的 Z profile 选择峰值层 `z_px`。横向 profile 严格从该单层提取，横向审核也显示同一层，不使用三层或最大值投影。轴向 profile 以同一 `z_px` 为中心，但横向和轴向分别执行质量筛选、人工决定与统计纳入。

主报告只显示 ROI 数量。内部保留 `line_id` 以支持审计，不在用户主报告中展示独立线条数。

线条模式的输出代表结构宽度与 PSF 的卷积。只有当线条自身直径相对系统分辨率可忽略时，才能把它解释为系统分辨率。

## 4. TIFF 与批处理

- 支持单个 `.tif/.tiff` 或包含 TIFF 的文件夹。
- 文件夹默认只读取第一层；`--recursive` 才遍历子目录。
- 每个 TIFF 单独生成 ROI 图和 profile 结果。
- 仅当模式、采样和理论参数一致时合并批次统计。
- `YX` 和 `ZYX` 可直接处理。
- 非单例 `C`/`T` 轴必须显式传入通道或时间点。
- 缺失或通用三维 axes 按已确认约定解释为 `ZYX`。

## 5. 输出与审核

自动分析目录至少包含：

- `fwhm_measurements.csv`：逐 ROI 坐标、FWHM、SNR、$R^2$、中心偏移、Tukey 标记和拒绝原因。
- `fwhm_summary.json`：物理参数 `opt`、运行参数 `run_parameter`、状态、逐方向统计和检测元数据。
- `SUMMARY.md`：简短统计与 `Index` 输出索引。
- `fwhm_boxplot.png`：横向与轴向共用零起点坐标轴，叠加全部 ROI 散点及 n、中位数、IQR。
- `candidates.png`：全部候选在原图上的位置、接受状态和 candidate ID。
- `review-assets/`：自动分析时预生成的合格 ROI 审核证据。荧光珠仍使用统一目录；线条分别写入 `XY/` 与 `Z/`。

线条模式另外生成：

- `candidates-XY.tif`：`ZYXS` 横向候选栈；一像素宽法线及 ROI 序号只画在候选峰值 Z 层。
- `candidates-Z.tif`：`ZYXS` 轴向候选栈；一像素宽标记覆盖实际 Z profile 范围，并在中心层标出 ROI 序号。
- `review-assets/XY/`：峰值 Z 单层裁剪、横向法线和横向高斯拟合。
- `review-assets/Z/`：中心 XY、XZ、YZ 视图和轴向高斯拟合。

不生成 XLSX、`profiles.png`、`profiles/` 或 `roi-verification.pdf`。单个 TIFF 不生成 `per-file/`；批量输入时，每个 TIFF 的带编号候选图、CSV 和 JSON 分别保存在 `per-file/<文件名-短哈希>/`，预生成审核图统一位于结果根目录的 `review-assets/`。

审核页面只提供保留/删除。自动合格 ROI 默认保留；删除原因不强制填写。审核直接读取预生成的 `review-assets/`。线条模式使用横向/轴向标签和方向特定决定；`manual_review_xy/z` 与 `reviewed_included_xy/z` 独立计算，一个方向的删除不影响另一个方向。操作立即写入 `roi-decisions.json`，生成结果时新建 `reviewed/<timestamp>/`，并按方向复制人工保留的审核证据；原始自动结果保持不变。

页面固定每行3项，每页最多150项；每页先加载30项，滚动接近页底时每次追加30项。翻页或切换方向时回到页首。该加载策略只影响浏览器呈现，不改变候选顺序、测量结果或决定键。

## 6. 科学报告建议

至少报告：

- 样品类型、采样尺寸、Z层排除、预设名称及版本。
- 候选数、质量合格 ROI 数、Tukey 排除数和人工删除数。
- 横向/轴向中位数、IQR、bootstrap 95% CI。
- 全部预注册的质量筛选阈值。
- 未筛选与筛选后的敏感性结果，尤其在论文补充材料中。

不能把单纯高斯拟合成功等同于结构真实，也不能为得到更好的分辨率数字而按组单独调节阈值。
